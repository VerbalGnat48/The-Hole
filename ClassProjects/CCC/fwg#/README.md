////////// Fun With Games! //////////

This is the final product of my first Vircon32 game.

Was made in Fall, 2023 from 10/19 -> 11/15 with each week building upon the last until this project.

Made in modified C language.

////////// fwg objectives //////////

Make a game in the Vircon32 emulator that uses sprites, player controll with movement, screen boundaries, collision detection, on-screen oppenents, projectiles, score indicator, and audio

////////// How to use //////////

Use for example: "./fwg3.sh fwg3.v32" to both "make" and run fwg3.
To make: "./fwg3.sh"
To run: "Vircon32 fwg3.v32"
